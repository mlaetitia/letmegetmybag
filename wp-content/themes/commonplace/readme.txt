A quiet, earthy editorial block theme for the multipotentialite.

== Description ==

Commonplace is a block theme built around the metaphor of a commonplace book - a personal notebook for collecting passages, observations, and projects across many domains. Five flat categories (Notes, Reading, Making, Growing, Going) each get their own accent colour against a shared cream foundation: plum, sage, terracotta, ochre.

Designed for writers, makers, and multipotentialites who pick things up, set them down, and circle back. Quiet typography, generous whitespace, one confident accent at a time.
